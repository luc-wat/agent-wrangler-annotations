# Agent Wrangler annotations

An [Agent Wrangler](https://github.com/PortSwigger/agent-wrangler) extension that brings a
comment-then-send flow to agent conversations: in a session's Chat view, highlight passages,
add a note to each, review or edit them, then press **Send all** to send the session one
numbered message quoting every excerpt with its note.

Works wherever core's Chat panel appears — plain board sessions and conversations inside
Wrangler² (a New idea's conversation, a step's Sessions, Phone control).

> Work in progress: this repository currently holds only the scaffold.
